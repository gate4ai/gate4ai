# UI/UX ревью gate4.ai (2026-10-21)

Отчёт — [index.html](index.html) (откройте локально в браузере: картинки рядом). Скриншоты реального UI свежей установки — `shots/`, новые макеты — `mockups/` (HTML и PNG).

Разделы: текущие пути и скриншоты, проблемы и нарушенные паттерны (I-01…I-24), упрощение и сокращённые пути, онбординг, что убрать в «Расширенные настройки», макеты M1–M5, приоритизированный список изменений.

Главное:
- **P0, безопасность умолчаний:** агент, созданный мастером, без вопросов читает весь `~` (включая `~/.ssh`), потому что у коннектора «Файлы» корень `~`, а чтение по умолчанию разрешено (I-01).
- Путь «установка → первое подтверждение»: 12 шагов → 6 с мастером первого запуска (M1).
- Меню: 8 разделов → 5; ~40 полей — в «Расширенные».
- Один язык интерфейса: английские описания манифестов и причины решения ядра в русском UI (I-03).
