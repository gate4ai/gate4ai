## Допущения

1. **Скрытые пути закрыты на уровне коннектора `files`, а не capability-проверки хоста.** Правило касается только файлов агента; WASM-коннекторам с явными путями оно не нужно. Скрытым считается любой компонент пути *ниже корня* — если владелец сам указал корнем скрытую папку (`~/.config/app`), её содержимое доступно. Открыть всё — настройка `allow_hidden: true` (в «Расширенных»).
2. **Начальный корень — `~/Documents`.** На уже настроенных установках корень `~` не меняется молча (это решение владельца) — показывается предупреждение и кнопка «Ограничить папкой…».
3. **Умолчание класса `read → allow` в модели политик остаётся** (спецификация). Мастер вместо умолчаний пишет явные правила по группам («Читать: само» → `allow`), поэтому то, что видит владелец, совпадает с правилами.
4. **«Разрешать всегда» создаёт правило сразу**, без промежуточной формы: кнопка называет, что именно будет разрешено (папка, сайт, адресаты). Правило видно в «Доступ → Правила», после сохранения — ссылка «уточнить». Спецификация («создаёт предложение правила») обновлена.
5. **`i18n` в манифестах официальных `email` и `browser` пока не добавляется:** манифесты разбираются строго (`KnownFields`), и daemon до этой версии не поставил бы новую версию коннектора. Переводы для них — каталог в ядре; в манифесты — после того как старые ядра выйдут из обращения (записано в технический долг спецификации).
6. **Папки и сайты из мастера — общие настройки коннектора** (`connectors.files.roots`, `connectors.browser.allowed_domains`): мастер добавляет к ним выбранные. Для файлов права агента дополнительно ограничиваются правилами с условием «внутри папки» и запретом вне выбранных папок, чтобы второй агент не получил папки первого.
7. **Группы действий в мастере — по классу эффекта** (читать / менять / отправлять / платить), подписи групп для официальных коннекторов — свои («Нажимать, заполнять, входить»). Работает для любого коннектора.
8. **Мастер открывается сам**, если агентов нет и мастер не пропущен (отметка в cookie браузера). Чек-лист на Главной остаётся для пропустивших.
9. **«Доступ» — раздел с вкладками** «Коннекторы» и «Правила» на прежних адресах (`/connectors`, `/policy`); адреса не меняются, ссылки и закладки работают.
10. **Секреты остаются на адресе `/vault`**, в меню — «Настройки → Пароли и учётки».
11. **Сообщения после действия хранятся в сессии** (одно последнее, показывается один раз). Параметры `?flash=` и `?error=` в адресе по-прежнему принимаются — для старых ссылок и ошибок без сессии.
12. **Установщик включает автозапуск по умолчанию** (раньше — только с `GATE4AI_START=1`, переменная продолжает работать). Отказ — `GATE4AI_NO_START=1`. Браузер открывается, только если есть графическая сессия (`DISPLAY`/`WAYLAND_DISPLAY`, macOS, Windows) и stdin/stdout не перенаправлены в CI (`CI` не задан).
13. **Мастер учётки сайта** подставляет поле логина `input[type=email], input[autocomplete=username], input[name*=login i], input[name*=user i], input[type=text]`, пароль — `input[type=password]`, отправку — Enter. Сложные формы — как раньше, YAML.
14. **Предпросмотр шаблона** считается применением шаблона к копии конфигурации и сравнением правил профиля.
15. **Основной язык интерфейса — английский, русский — перевод** (указание владельца). Исходные строки в шаблонах и коде — английские, перевод — каталог `ru`. Язык выбирается переключателем (cookie `g4a_lang`), без него — по `Accept-Language` браузера (`ru` → русский), иначе английский. Отчёт и документы проекта остаются на русском, как остальная документация. Вывод установщика — английский, как и CLI.

## Как проверяется

- `go build ./... && go vet ./... && go test ./...` в `gate4ai/` и `www/`; новые тесты на каждый пункт (httptest Web UI, коннектор `files`, CLI, сайт).
- Вживую: свежий daemon в отдельном каталоге с подменённым `HOME` — путь A мастером, путь D, скриншоты в `shots-after/`.
