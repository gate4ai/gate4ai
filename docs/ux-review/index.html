1. Коротко

За последние недели Web UI вырос из «YAML в textarea» в полноценный интерфейс: чек-лист, мастер агента с автоподключением, магазин коннекторов, конструктор правил, мастер Telegram. Блокеров (когда без терминала или YAML не пройти) на основном пути больше нет. Мешают другое: объём (8 разделов, на одной странице по 6 блоков), язык (английские описания и технические причины рядом с русским интерфейсом) и модель «профилей и классов», которую новичку приходится понять до первого действия.

12 → 6шагов от установки до первого подтверждения (локальный агент)
~15 → 7шагов для Claude.ai / ChatGPT
8 → 5пунктов главного меню
~40полей и кнопок уходят в «Расширенные»
Главная находка — опасное умолчание (P0). Мастер агента по умолчанию даёт профиль «чтение — само», а у встроенного коннектора «Файлы» корень ~. В итоге агент без единого вопроса читает любой файл в домашнем каталоге, в том числе ~/.ssh/id_ed25519 и ~/.claude.json с токеном самого gate4ai. Проверено на подменённом HOME с фейковым ключом: files.read ~/.ssh/id_ed25519 → allow, «no rule matched; default for effect class "read" is allow». Обычный пользователь не догадается, что «Файлы» уже открыты на весь дом. Исправление — в I-01.

Пять изменений с наибольшим эффектом:

  1. Безопасные умолчания для файлов: без явно выбранной папки — ничего; скрытые каталоги и ключи закрыты всегда (I-01, I-02).
  2. Мастер первого запуска из трёх экранов вместо чек-листа со ссылками в пять разделов: агент → что можно (папки и сайты простыми переключателями) → проверка с живым первым подтверждением (макеты M1).
  3. Запрос подтверждения человеческим языком: что, где и что изменится, без дампа и английской причины; кнопка «Разрешать в этой папке всегда» (I-04, макеты M2 и M3).
  4. Пять пунктов меню: Главная (очередь подтверждений) · Агенты · Доступ (коннекторы и правила) · Журнал · Настройки; секреты, YAML, версии, списки, симулятор — в «Расширенные» (I-07, раздел 7).
  5. Один язык: русские описания коннекторов и действий в манифесте, перевод причин решения ядра (I-03).

2. Как проверялось

  • Собран gate4ai из worktree main и запущен как свежая установка: пустой каталог данных, --keystore file, Web UI на 127.0.0.1:7499, свои сокеты. Daemon сам поставил browser из магазина, как у нового пользователя.
  • Скриншоты сняты headless Chrome (Playwright) в 1280×800 и 390×844 (телефон), светлая тема. На скриншотах после шага «Добавить агента» daemon запущен с подменённым HOME: автоподключение Claude Code писало в тестовый .claude.json, а не в настоящий. Поэтому пути на этих экранах длинные (/tmp/claude-1000/…/fh/). У реального пользователя они короче, но проблема длинных путей в заголовках и сообщениях остаётся (I-15).
  • Агент имитирован через CLI с выданным мастером токеном: files.list (разрешено), files.append и files.write (запрос подтверждения), затем решение в Web UI.
  • Сайт www собран и запущен локально (GATE4AI_WWW_LISTEN=127.0.0.1:8099) с настоящим индексом registry.
  • Трей и уведомления ОС не проверялись: в headless-окружении нет графической сессии. Telegram и relay — только экраны настройки, без реальной регистрации.
  • Прочитаны docs/ui-plan.md, docs/cli-ux.md, quickstart.md, README, www/UX-ONBOARDING.md, спецификация. Отчёт не повторяет уже сделанное по этим документам, а начинает с того места, где они закончили.
  • Для оценки — эвристики Нильсена (N1–N10), WCAG 2.2 AA, принципы прогрессивного раскрытия и безопасных умолчаний.

3. Текущие пути и скриншоты

3.1. Путь A: установка → локальный агент → первое подтверждение

Лучший случай: Claude Code уже стоит на компьютере, пользователь не ошибается.

3.2. Путь B: облачный агент (Claude.ai, ChatGPT)

  1. Шаги 1–4 пути A.
  2. Обзор → «Настройки relay» → «Зарегистрироваться на relay.gate4.ai» → ждать выпуска сертификата.
  3. Агенты → «Добавить агента» → «Claude.ai, ChatGPT» → шаг 2 (те же 9 полей) → «Добавить».
  4. Скопировать адрес MCP → «Получить код подключения» → скопировать код.
  5. Claude.ai → Settings → Connectors → Add custom connector → вставить адрес → авторизация → ввести код.
  6. Попросить агента сделать действие → подтвердить.

Около 15 шагов в трёх местах (Web UI, сайт Claude, терминал). Плитка «Claude.ai, ChatGPT» не предупреждает, что сначала нужен relay; пользователь узнаёт об этом только на странице агента.

3.3. Путь C: ограничить доступ (папка, сайты, почта)

  1. Коннекторы → карточка «files» → «Настроить».
  2. Поле «Разрешённые папки» (textarea, по строке) → «Сохранить».
  3. Ниже — «Кому доступен» (профили) с отдельной кнопкой «Сохранить», затем таблица действий с выпадающими «Решение (профиль default)».
  4. Чтобы задать решение для своего агента — переключить вкладку профиля или уйти в «Правила».

У «Браузера» до списка сайтов пользователь проходит 8 полей (модель, ключ модели, профиль Chrome, путь, CDP, движок…) и таблицу из 12 действий на английском.

3.4. Остальные экраны (свежее состояние)

3.5. Что уже хорошо и что стоит сохранить

  • Все страницы работают без JavaScript, формы серверные — надёжно и быстро.
  • Пустое состояние «Агентов» (03): объясняет, что это, и даёт одну кнопку.
  • Определение установленных клиентов («найден на этом компьютере») и автоподключение с резервной копией конфигурации.
  • Форма правила «одной фразой» (25, 37) — правильный паттерн; правило из запроса подставляет действие и папку.
  • Мастер Telegram (16): нумерованные шаги, следующий шаг заблокирован до предыдущего.
  • Тёмная тема по prefers-color-scheme, адаптивная вёрстка, живая очередь подтверждений.

4. Проблемы и нарушенные паттерны

Приоритет: P0 — безопасность или срыв первого пути, P1 — заметно мешает, P2 — шлифовка. Эвристики Нильсена: N1 — видимость состояния, N2 — язык пользователя, N3 — контроль и свобода, N4 — единообразие, N5 — предотвращение ошибок, N6 — узнавание вместо припоминания, N7 — гибкость, N8 — минимализм, N9 — понятные ошибки, N10 — справка.

Путь A (локальный агент): 12 → 6 шагов

Путь B (Claude.ai / ChatGPT): ~15 → 7 шагов

6. Онбординг

Цель из www/UX-ONBOARDING.md остаётся верной: первое разрешённое и первое подтверждённое действие за 5 минут, без YAML и второго терминала. Блокеров на этом пути больше нет; осталось убрать лишние решения и дать момент «ага».

6.1. Принципы

  • Мастер вместо чек-листа. Чек-лист — список ссылок в разные разделы, каждый со своими полями. Мастер — три экрана, на каждом одно решение. Чек-лист остаётся на Главной, пока мастер пропущен.
  • Спрашивать задачу, а не модель. «Какой ассистент?» и «Что ему можно?» вместо «профиль», «шаблон», «коннектор».
  • Безопасно по умолчанию, но не молча. Файлы — только выбранные папки; изменения — «спрашивать»; скрытые каталоги закрыты всегда (I-01).
  • Видимый результат. Шаг «Проверка» показывает живую ленту: агент подключился → прочитал → хочет изменить → «Разрешить». Это первое подтверждение и одновременно проверка всей цепочки.
  • Каналы — после первого успеха. Telegram и push предлагаются на шаге 3, когда пользователь уже понял, зачем они.
  • Автозапуск — переключатель в мастере, включён по умолчанию. Не отдельная команда в терминале.
  • Всегда можно уйти. «Пропустить, настрою сам» в шапке мастера; мастер можно открыть снова с Главной.

  • /install: после установки — одна команда gate4ai ui и картинка мастера вместо кнопки «README» (I-24). Параметры установщика (GATE4AI_VERSION и др.) — под «Для администраторов».
  • Каталог: русские названия и описания (та же локализация манифеста, что в I-03); заголовок карточки — «Почта», а не email. На странице коннектора семь возможностей email сводятся к двум человеческим строкам (как в I-18), сырые строки — под спойлером. Кнопка «Установить» по-прежнему даёт только команду: стоит добавить «Открыть в gate4.ai» (http://127.0.0.1:7431/connectors?install=email), как предлагает UX-ONBOARDING.md С7.
  • Анимация появления секций (animation-timeline: view()) скрывает содержимое при печати и на снимках всей страницы; при prefers-reduced-motion всё корректно. Мелочь, но для печати стоит отключать: @media print.

10.2. Установщик

Последние строки install.sh — «Next steps» из трёх команд на английском и ссылка на README. Предложение: по умолчанию включать автозапуск (флаг GATE4AI_NO_START=1 для отказа — обратное нынешнему GATE4AI_START=1) и, если есть графическая сессия, открыть Web UI сразу; иначе — одна строка «Откройте: gate4ai ui». Язык — по LANG, как уже сделано для трея.
