# connectors/auth — auth-модули

Здесь будут лежать auth-модули (коннекторы авторизации) gate4ai: `auth-imap`, `auth-smtp`, `auth-oauth2`, `auth-totp`, `auth-ssh`, `auth-sigv4` и другие. Каждый модуль — в своём каталоге `connectors/auth/<модуль>` этого репозитория и выпускается вместе с ним (одна версия, один релиз; см. [docs/publishing.md](../../docs/publishing.md)).

## Зачем они нужны

Коннектор с бизнес-логикой (почта, банк, ЖКХ) не должен видеть секреты. Он работает только с алиасом учётки (`@mail.work`), а пароль, токен или ключ подставляет ядро или auth-модуль, и только по адресу привязки учётки. Поэтому коннектору нельзя ни увести секрет на свой сервер, ни вернуть его агенту в ответе.

Auth-модуль реализует только протокол входа или подписи: IMAP LOGIN, XOAUTH2, OAuth-потоки, TOTP, SSH, HMAC, SigV4. Модули задуманы так:

- **лёгкими** — без бизнес-логики, небольшого объёма, их можно строго проверить при ревью;
- **переиспользуемыми** — один модуль служит многим коннекторам: например, `auth-ssh` проверяют один раз, а пользуются им все SSH-коннекторы.

Auth-модуль — это не коннектор в обычном смысле: агенту он не виден и действий не имеет. Его вызывает ядро для слота учётки.

Подробности — в [secret-architecture.md](../../gate4ai/docs/secret-architecture.md).
