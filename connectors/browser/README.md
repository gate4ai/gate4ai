# Коннектор «Браузер» для gate4.ai

Браузерный воркер в выделенном профиле настоящего Chrome (CDP, Stagehand) — нативный пакет (`runtime: native`): отдельный процесс под надзором хоста [gate4ai](https://github.com/gate4ai/gate4ai). Работает без песочницы, с правами пользователя, поэтому магазин принимает нативные пакеты только от gate4.ai.

- **Агенту без сеанса:** `read` (текст страницы), `screenshot` (снимок элемента — доказательство), `extract` (данные по инструкции, модель задаёт владелец) на сайтах из настроек: `allowed_domains` или режим `blocklist` с `blocked` (адреса этого компьютера и локальной сети закрыты всегда). Итоговый адрес проверяется и после редиректов.
- **Агенту в сеансе** (исследовать сайт, писать по нему коннектор): `open` без `session` начинает сеанс и возвращает его id (переход ждёт, пока сеть успокоится; `wait_for_selector` / `wait_for_text` — дождаться нужного блока), дальше на той же странице — `observe` (текст; `selector` — только внутри элемента, `elements: true` — видимые ссылки, кнопки и поля с однозначным CSS-селектором, `outline: true` — структура контейнеров), `act` (click / fill / press / wait по селектору и видимому тексту, класс `write`; `expect_selector` / `expect_text` / `expect_url_change` — без ожидаемого результата ответ `not_found`, а не ok), `network` (fetch / XHR страницы к разрешённым сайтам по CDP Network — метод, адрес, статус, начало ответа JSON; `all_sites` — и к чужим; токены, пароли, ответы входа и `redact_params` скрыты, тела запросов не пишутся, странице ничего не подменяется), `page_extract`, `page_screenshot`; `close` освобождает страницу и возвращает записанные шаги без пустых аргументов — фикстуру для `hosttest.Replay` (`close --all` — все сеансы, если id потерян). Страница одна: пока сеанс открыт, остальные вызовы браузера получают `busy` с подсказкой; сеанс без действий закрывается через 10 минут; прерванный вызов прерывается и в пакете. Адрес проверяется после стабилизации: тихий вход через SSO не обрывает страницу. Одноразовые коды в адресах (`?code=…`) в ответах скрыты.
- **Вход по учётке** (`credentials` в конфигурации gate4ai): `login {session, account}` вводит поля учётки (константы и секреты Vault) на открытой странице входа и отправляет форму — `logged_in`, `submitted` или `still_on_login`; `fill_secret {account, field, selector}` — одно поле без отправки (для коннекторов входа), `source: human` — код, который ввёл человек. Значения хост передаёт пакету только в этих действиях; они не попадают в ответ, шаги сеанса, ошибки и лог. Проверки до ввода: origin страницы — из `bind` учётки (`wrong_origin`), поля найдены, видимы и нужного типа — секрет только в `input[type=password]`, если у поля нет `type: text` (`form_mismatch`). После ввода секрета страницу нельзя читать (`observe`, `network`, `page_extract`, `page_screenshot`, `fill` — `secret_on_page`) до перехода верхнего документа; `click`, `press`, `wait` и `fill_secret` работают. Страница может быть на сайте входа доступной учётки вне списка сайтов (редирект на вход её не закрывает), а ответы `open` / `observe` / `network` там подсказывают `login_required`. Учётку со сложным входом (`via`) ведёт коннектор входа — его вызывает хост.
- **Другим коннекторам** (`service_call`, контракт 1): `open`, `observe`, `act`, `page_extract`, `page_screenshot`, `login`, `fill_secret` (учётка — алиас или слот коннектора). Страница — одна на корневое действие агента, сайты — `params` вызывающего (`{mode, domains, blocked}`), после каждого действия адрес проверяется снова. Клиент — `gate4ai contract gen manifest.yaml`.

## Установка

```sh
gate4ai connectors install browser                 # из магазина gate4.ai (ставится и сам при первом запуске)
# или своя сборка под этот компьютер:
gate4ai connectors install . --dev
```

Настройки — `connectors.browser` в конфигурации gate4ai: `allowed_domains`, `mode`, `blocked`, `engine` (stagehand | cdp), `cdp_url`, `chrome_path`, `profile_dir`, `model`, `model_key` (алиас Vault: значение хост передаёт пакету по `capabilities.reveal`), `max_text_chars`, `redact_params` (параметры адресов и поля JSON с личными идентификаторами сайта — `network` их скрывает).

Chrome запускается с `--disable-blink-features=AutomationControlled` (иначе с портом отладки `navigator.webdriver = true`, и антифрод сайтов видит автоматизацию), одной вкладкой; для `engine: stagehand` — ещё с `--remote-allow-origins=*` (расширению Stagehand нужно подключиться к DevTools; порт слушает только 127.0.0.1). Если окно Chrome закрыли, следующий вызов подключается заново или запускает Chrome; при остановке пакета запущенный им Chrome закрывается.

## Разработка

```sh
go test ./...                                     # коннектор — на sdk-go/hosttest, воркер — на фейковом CDP
gate4ai connectors pack .                         # пакет под каждую платформу из manifest.platforms + browser-<версия>.platforms.json
gate4ai connectors install . --watch              # поставить в свой daemon из исходников и пересобирать на каждое сохранение
```

Несовместимое изменение действий из `services` — только с повышением `contract` в манифесте (CI проверяет `gate4ai contract diff` с прошлым тегом).
